Changelog

Every change to raga, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

Unreleased

  • New screenshots in the Spatial look, taken with made-up demo data (WebP, sharp on high-density screens).
  • The website, closer to Vayu's own: the tool's screenshot blurred behind the page, a centred hero with the logo and the verse, the page you're on as the white pill, glass "On this page" and footer panels, releases as cards. No glow behind the logo, no coloured line beside the verse.
  • Spatial look: rounder tiles.
  • The website has Vayu's Spatial look: graphite glass, a floating navigation bar, near-white for links and the main button, and the tool's own colour only as its signature (the logo's glow, the shloka's line, the release dots). No more all-caps labels.

v0.3.02026-11-09Release notes

  • Vim keys (Vyom 0.7, ADR 0008): NORMAL and INSERT modes, Space as the leader with a which-key strip, ? and Space ? list every key, Space Space is a palette, counts (5j), gg / G, H / L for tabs. It opens in INSERT (search-first): type, then Esc for NORMAL. Needs Vyom 0.7.0.
  • Its keys are data (raga/vim.py); scripts/keybinds.py writes the # keybind: lines and the README's key tables from them, and --check (CI) fails when they drift.
  • o plays the other way (Shift+Enter still does), y y copies the link, Space a q queues, Space o b opens it on YouTube, Space y t copies the title, Space r searches again past what's remembered.
  • Ctrl+Enter queues the music on the Video tab too (it played the video, which wasn't documented).
  • Every corner is rounded: the website's callouts.
  • A logo and a shloka at the top of the README and the website: every Vayu tool has them now.
  • Screenshots in the README and on the website.
  • o and Space a q typed before the results arrive wait for them, so they never play or queue the previous search's song.

v0.2.12026-10-24Release notes

  • A thumbnail that can't be fetched is logged (debug), not swallowed.
  • Logs are in the journal (Vyom 0.3.2): the README, CONTRIBUTING and the bug report form say journalctl --user -u vyom -u vyom-daemon -b.

v0.2.02026-10-24Release notes

  • The Music / Video tabs switch like every Vyom tool's tabs (Vyom 0.3.0): Ctrl+H / Ctrl+L or Ctrl+1 / Ctrl+2, instead of Ctrl+M. Needs Vyom 0.3.0.

v0.1.32026-10-21Release notes

  • A website (GitHub Pages, https://theyashsawarkar.github.io/raga/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.22026-10-21Release notes

  • Music plays in nāda (the music player) when it's installed: it streams the song, lines up YouTube's mix after it, shows the lyrics and can download it. Without nāda, music still goes into MPD through rmpc. New setting nada_command (default nada; empty uses rmpc).

v0.1.12026-10-21Release notes

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.02026-10-19Release notes

  • First release, as its own repository: youTube music and video. Replaces music-search.py in Vayu.
  • Search as you type (yt-dlp, no Invidious), with thumbnails, durations, channels and views.
  • Music goes into MPD's queue through rmpc and plays at once; video opens in mpv, capped at 1080p.
  • Shift+Enter plays the other way; Ctrl+Enter only queues the music.
  • Which queue entry plays is read from the queue itself, before and after adding: rmpc addyt exits 0 even when its download failed.
